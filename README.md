# 🎵 Spotify Music Analytics Dashboard | Power BI

An interactive **Spotify Music Analytics Dashboard** built with **Microsoft Power BI** to analyze songs, artists, albums, popularity, music trends, and overall song performance.

The dashboard combines **Power BI, DAX, data modeling, interactive navigation, and Spotify-inspired UI design** to transform raw Spotify data into meaningful and easy-to-understand insights.

# 🎯 Project Objectives

The main objective of this project is to transform Spotify music data into an interactive analytics solution that can answer questions such as:

- Which artists have the most songs?
- Which artists have the highest popularity?
- Which songs are most popular?
- How are songs distributed between albums and singles?
- How many explicit and non-explicit songs are available?
- How does song popularity change over time?
- Which months have the highest number of song releases?
- Which artists have the most #1 hits?
